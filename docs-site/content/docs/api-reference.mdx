### Utility Functions

These helper functions follow the exact technical specifications in the [ABA PayWay Official Developer Portal](https://developer.payway.com.kh/overview-865678m0).

<Callout title="How to find these in ABA Portal" type="info">
In [developer.payway.com.kh](https://developer.payway.com.kh/), click on **"Accept payments"** (or **"Purchase API"**) in the left navigation sidebar. You will see the full parameters list and security specs.
</Callout>

```typescript
import {
  generateTransactionId,
  getABATimestamp,
  formatPhoneForABA,
  getQRExpiration,
  generateABAHash,
} from "aba-payway-sdk-unofficial";
```

#### 1. `generateTransactionId()`
- **What it does**: Creates a unique ID for each order (e.g. `EA1740234567abcd`).
- **ABA Requirement**: Must be unique, alphanumeric string with a maximum length of 20 characters (`tran_id`).
- **Where in ABA Docs**: Inside **Ecommerce Checkout > Purchase** under parameter `tran_id`.
- **Direct Official Link**: [ABA PayWay Purchase Endpoint](https://developer.payway.com.kh/purchase-14530820e0)

#### 2. `getABATimestamp()`
- **What it does**: Returns the current time as `YYYYMMDDHHmmss` in UTC (e.g. `20260823150500`).
- **ABA Requirement**: ABA verifies transaction creation time in UTC to prevent expired or replayed requests (`req_time`).
- **Where in ABA Docs**: Inside **Ecommerce Checkout > Purchase** under parameter `req_time`.
- **Direct Official Link**: [ABA PayWay Purchase Request Specs](https://developer.payway.com.kh/purchase-14530820e0)

#### 3. `formatPhoneForABA(phone)`
- **What it does**: Formats any international or domestic Cambodian phone number to domestic format (e.g. `+855 12 345 678` → `012345678`).
- **ABA Requirement**: ABA expects local 0-prefix format for customer phone numbers (`phone`).
- **Where in ABA Docs**: Inside **Ecommerce Checkout > Purchase** under optional parameter `phone`.
- **Direct Official Link**: [ABA PayWay Optional Parameters](https://developer.payway.com.kh/purchase-14530820e0)

#### 4. `getQRExpiration()`
- **What it does**: Generates an expiration Date set exactly 15 minutes into the future.
- **ABA & NBC Requirement**: Standard dynamic KHQR payment codes expire after 15 minutes to avoid unpaid orphan transactions.
- **Direct Official Link**: [NBC Bakong Developer Specification](https://api-bakong.nbc.gov.kh/document) & [ABA KHQR Guideline](https://developer.payway.com.kh/khqr-guideline-3192101f0)

#### 5. `generateABAHash(params, apiKey)`
- **What it does**: Calculates a Base64 HMAC-SHA512 cryptographic signature across all parameters in ABA's strict sequence.
- **ABA Requirement**: Every API request must have a valid `hash` generated with your `apiKey`. If parameters are in the wrong order or missing, ABA responds with code `1: Wrong Hash`.
- **Where in ABA Docs**: Under **Security & Hashing Sequence** for Standard Purchase API.
- **Direct Official Link**: [ABA PayWay Ecommerce Checkout Specs](https://developer.payway.com.kh/ecommerce-checkout-3158159f0) & [API Endpoints Overview](https://developer.payway.com.kh/api-endpoints-984508m0)
