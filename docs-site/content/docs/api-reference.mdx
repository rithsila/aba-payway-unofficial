### Utility Functions

```typescript
import {
  generateTransactionId,
  getABATimestamp,
  formatPhoneForABA,
  getQRExpiration,
  generateABAHash,
} from "aba-payway-sdk-unofficial";
```

- `generateTransactionId(): string`: Generates a random, unique alphanumeric ID prefixed with `EA` (up to 20 characters).
- `getABATimestamp(): string`: Formats current date/time to `YYYYMMDDHHmmss` string for ABA request timestamps.
- `formatPhoneForABA(phone: string): string`: Converts phone numbers into standard Cambodian domestic 0-prefix format (e.g. `+855123456` → `0123456`).
- `getQRExpiration(): Date`: Returns a Date object 15 minutes into the future.
- `generateABAHash(params: HashParams, apiKey: string): Promise<string>`: Computes base64 HMAC-SHA512 hash in ABA's required parameter sequence.
