---

Initialize `ABAPayWay` by passing an `ABAConfig` object:

```typescript
import { ABAPayWay, type ABAConfig } from "aba-payway-sdk-unofficial";

const config: ABAConfig = {
  merchantId: "ec460802",
  apiKey: "your_api_key_here",
  baseUrl: "https://checkout-sandbox.payway.com.kh",
  webhookSecret: "your_webhook_secret", // optional
};

const aba = new ABAPayWay(config);
```

---

## Configuration Properties

| Option | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `merchantId` | `string` | Yes | Your assigned merchant ID from ABA Bank. |
| `apiKey` | `string` | Yes | Public/Private API key used for HMAC-SHA512 request signing. |
| `baseUrl` | `string` | Yes | Gateway base URL. |
| `webhookSecret`| `string` | No | Secret used to verify incoming pushback notifications. |

## Environments

- Base URL: `https://checkout.payway.com.kh`
