Initialize `ABAPayWay` by passing an `ABAConfig` object:

```typescript
import { ABAPayWay, type ABAConfig } from "aba-payway-sdk-unofficial";

const config: ABAConfig = {
  merchantId: "ec460802",
  apiKey: "your_api_key_here",
  baseUrl: "https://checkout-sandbox.payway.com.kh",
  webhookSecret: "your_webhook_secret", // optional
};

const aba = new ABAPayWay(config);
```

---

## Configuration Properties

| Option | Type | Required | Description | Official Reference |
| :--- | :--- | :--- | :--- | :--- |
| `merchantId` | `string` | Yes | Your assigned merchant ID from ABA Bank. | [ABA Ecommerce Checkout](https://developer.payway.com.kh/ecommerce-checkout-3158159f0) |
| `apiKey` | `string` | Yes | Public/Private API key used for HMAC-SHA512 request signing. | [ABA Security & Hash](https://developer.payway.com.kh/purchase-14530820e0) |
| `baseUrl` | `string` | Yes | Gateway base URL (Sandbox or Production). | [ABA API Endpoints](https://developer.payway.com.kh/api-endpoints-984508m0) |
| `webhookSecret`| `string` | No | Secret used to verify incoming pushback notifications. | [ABA Pushback Notification](https://developer.payway.com.kh/ecommerce-checkout-3158159f0) |
