The unofficial, edge-ready TypeScript SDK for integrating ABA Bank PayWay payment gateway in Cambodia.

<Callout title="Why this project exists" type="info">
Many online tutorials make ABA PayWay integration sound very complicated, and people worry about losing money or doing it wrong. We created this easy SDK with AI assistance to make accepting payments safe, fast, and simple for everyone in Cambodia.
</Callout>

## What Does This SDK Do? (Simple Explanation)

1. **Creates KHQR Codes & Links**: Let your customers scan with ABA Mobile, Bakong, or any bank app.
2. **Handles Signatures (HMAC-SHA512)**: Automatically creates safe security hashes so you don't make mistakes.
3. **Checks Payment Status**: Asks ABA if the customer already sent money.
4. **Verifies Webhooks**: Checks real-time alerts from ABA safely to protect against hackers.
5. **Zero Extra Dependencies**: Works on Node.js, Next.js, Bun, Deno, and Cloudflare Workers.

## Installation

Install the package from NPM:

```bash
npm install aba-payway-sdk-unofficial
```

Or using Yarn, PNPM, or Bun:

```bash
pnpm add aba-payway-sdk-unofficial
```

## Quickstart

```typescript
import {
  ABAPayWay,
  generateTransactionId,
} from "aba-payway-sdk-unofficial";

// 1. Initialize client
const aba = new ABAPayWay({
  merchantId: process.env.ABA_MERCHANT_ID!,
  apiKey: process.env.ABA_API_KEY!,
  baseUrl: "https://checkout-sandbox.payway.com.kh",
});

// 2. Create a purchase
const transactionId = generateTransactionId();

const purchase = await aba.createPurchase({
  transactionId,
  amount: 10.0,
  currency: "USD",
  items: "Standard Subscription",
  firstName: "Dara",
  lastName: "Sok",
  email: "dara@example.com",
  returnUrl: "https://yoursite.com/payment/success",
  cancelUrl: "https://yoursite.com/payment/cancel",
});

if (purchase.success) {
  console.log("PayWay Web Checkout:", purchase.checkoutUrl);
  console.log("ABA Mobile App Deeplink:", purchase.abapayDeeplink);
  console.log("Raw EMV QR Data:", purchase.qrString);
}
```
