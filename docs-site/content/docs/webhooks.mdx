title: Webhooks
description: Receiving instant payment notifications and signature verification
---

When a customer pays, ABA PayWay posts a JSON callback to your webhook URL with signature header `X-PAYWAY-HMAC-SHA512`.

Use `verifyWebhook()` to securely validate the notification:

```typescript
import { ABAPayWay } from "aba-payway-sdk-unofficial";

export async function POST(req: Request) {
  const rawBody = await req.text();
  const signature = req.headers.get("x-payway-hmac-sha512") || "";
  const webhookSecret = process.env.ABA_WEBHOOK_SECRET!;

  const isValid = await aba.verifyWebhook(rawBody, signature, webhookSecret);

  if (!isValid) {
    return new Response("Invalid signature", { status: 401 });
  }

  const payload = JSON.parse(rawBody);
  console.log("Verified Transaction:", payload.tran_id, payload.status);

  return new Response("OK", { status: 200 });
}
```

---

## Security Details

- The verification uses **constant-time byte comparison** (`^` XOR accumulator) to ensure resilience against side-channel timing attacks.
- JSON keys are automatically sorted alphabetically (`ksort`) before calculating the HMAC-SHA512 hash, matching ABA's exact pushback algorithm.
